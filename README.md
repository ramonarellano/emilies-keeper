# Emilies Keeper

Et samarbeidsprosjekt mellom Emilie og pappa. 🚀

## Om prosjektet

_Kommer snart – her beskriver vi hva vi bygger._

## Slik jobber vi sammen

1. Hent siste versjon: `git pull`
2. Lag en egen gren for det du jobber med: `git switch -c min-endring`
3. Gjør endringer, og lagre dem: `git add .` og `git commit -m "Hva jeg gjorde"`
4. Send grenen til GitHub: `git push -u origin min-endring`
5. Lag en pull request på GitHub, så ser vi over det sammen før det flettes inn.
